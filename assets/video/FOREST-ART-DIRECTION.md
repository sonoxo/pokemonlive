# 2D 林间对战背景 · 2026-09-05

## 范围与画面约束

保留当前网页 2D 动画，不引入 Three.js、Blender 或模型。以现有 anime-v3 无 UI 首帧为编辑源，仅替换环境；皮卡丘在左下、小火龙在右上，角色设计、相对比例、姿势和清晰墨线不变。血量面板仍由 HTML 叠加，战斗逻辑不变。

参考动画中林间空地的构图：前景少量草叶框边、中景日照草地与浅土色对战区、两侧树冠、远处偏蓝绿树线与天空。中央空地低对比，树木细节集中在边缘，不遮挡角色或上左／下右 HUD 安全区。保持平涂赛璐璐角色和柔和手绘背景，不要写实材质、景深模糊、体积光、3D 光泽或环形石墙。

## 技术约束

- 固定机位，宽幅约 16:9；角色锚点沿用源帧，不移动 UI。
- PNG 首帧，sRGB、不透明；MP4 H.264 待机 5 秒，可循环；网页平滑采样。
- 待机仅呼吸、耳朵小动作、火焰和草叶微动；首尾同图约束，不打斗、不漂移。
- 听令短片保持 5 秒、现有特写节奏和相同新环境；服务端开场尾帧必须来自该新短片。
- 保留原 v3 素材可回退。初次制作仅生成一套首帧、待机和听令素材，人工及页面检查后接入。

生成输入只使用本项目既有 anime-v3 首帧。新图由内置 imagegen 编辑，再通过现有 fal H3 Turbo 生成配套视频。AI 生成不代表获得宝可梦角色使用授权，仍保留项目本地非商业原型限制。完整提示词、生成记录与验证结论见同目录 forest 素材清单。
