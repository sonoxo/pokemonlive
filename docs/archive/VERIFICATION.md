## 已接通

- 选择招式立即进入原战场内的听令特写；画外喊招使用浏览器中文语音合成，声音控制可关闭。浏览器没有中文语音时仍显示文字指令。
- 默认皮卡丘／小火龙匹配的过渡片预生成并本地复用，不含攻击或命中结果。其它阵容、异常状态不复用错误角色桥段。
- 后台同时规划及生成。DeepSeek 规划预算 1.5 秒，超时由不可变战斗事实编排本地镜头。
- 首段以过渡片实际尾帧启动 Turbo；其它阵容保留双物种参考图开场。后续始终由上一段实际尾帧续接。
- 双视频播放器：在下一段实际首帧解码后才隐藏上一段，不依赖单纯 src 切换或 canplay。首段慢时续播默认待机呼吸；续段慢时保留尾帧。
- HP 使用展示快照及媒体时间提示点更新，最终结果仅由引擎决定；不会再重播一遍像素攻击。提示点是计划时间，不是对生成视频进行视觉命中检测，仍可能存在亚秒级偏差。
- 原始生成视频、真实战斗事实、实际提示词和播放埋点保存在 `.local/runs/<session-id>/`，不含 API key；该目录不对静态服务公开。

## 无额外费用的浏览器回归

使用 `.local/replay-server.mjs` 在独立本地端口回放已有素材，不调用 fal／DeepSeek。它用于检验播放器生命周期，不作为生成质量或真实伤害演出的证明。记录在 `.local/replay-evidence.jsonl`。

- 已缓冲片段：接播约 34 ms，完整返回可操作界面。
- 故意延迟首段：过渡在 5.243 秒后切回动态待机，9.230 秒开始首段；现场读取到待机视频未暂停、攻击视频尚未显示、双方 HP 未提前变动，截图无黑底。
- 故意延迟续段：第一段结束后保留画面，14.129 秒接上第二段，最终恢复操作。
- 故意让第二段失败：第一段完成后恢复操作，显示动画中断但保留引擎战斗结果。
- 桥段中跳过后立即下一回合，再在生成期间重新对战：恢复 TURN 01、双方满 HP、无残留可见攻击视频。

`npm test`：85 项全部通过。覆盖真实规则引擎、参考图／尾帧传递、媒体缓冲及真实首帧揭示、取消和晚到回调、事件仅应用一次、残余伤害与下一行动的混乱自伤／醒来／麻痹分离等。

## 限制

- 不能保证每次点击后 5 秒内开始攻击，或者任何队列条件下都无停顿；保证播放器不主动清空成黑屏，并在素材就绪时续播。
- 默认预生成听令／待机素材目前只覆盖皮卡丘对小火龙；其它阵容是像素后备战场加内联攻击视频。
- AI 提示词改善动作和物种一致性，但不是逐帧确定性动画。命中时点在本次抽帧检查后做了招式级校准，未来生成仍可能偏离。
- 没有独立完成手机浏览器和所有阵容的真实付费生成验收。

fal 接口依据：[H3 Max Turbo 官方 API](https://fal.ai/models/minimax/h3-max-turbo/image-to-video/api)，支持首尾帧及 Data URI 文件输入。密钥始终仅在服务端读取。
