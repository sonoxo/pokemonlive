## 本地无付费浏览器回放

服务 `.local/prewarm-replay.mjs`（4191），使用既有真实视频作替身。日志 `.local/prewarm-qa/replay.jsonl`，这些数据验证流程，**不证明替身视频的招式或物种正确**。

| 场景 | 实测结果 |
| --- | --- |
| fast 麻痹回合 | 首攻击播放后 1ms 启动状态预热；约 6.2s 隐藏加载，15.8s 回合结束，待机直接可用、指令恢复 |
| delayed 状态素材延迟 15s | 约 15.8s 回合结束后指令已恢复；正确攻击尾帧继续显示，约 20.7s 状态待机接管 |
| switch 拆分换人 | 54ms 提交放出，收回已开始；约 5.3s 切入放出并同时请求四类新阵容素材；15.9s 新阵容回合结束 |
| slow-sendout 放出延迟 15s | 收回结束后保持其尾帧；15.8s 才切放出，期间未清空可见播放器；后续敌方攻击、恢复指令均正常 |

针对“收回已结束、放出 POST 迟迟未返回”的实际 `playSwitchEvent` 函数回归：点跳过 50ms 内退出；迟到响应不得修改播放器，仍获取 key 后取消远端任务。队列取消、状态旧结果覆盖、单段 ready 但整场未 ready、KO 预收回均有自动化测试。

## 限制

Reference 的布局参考并非硬性首帧约束，镜头切换可能有构图差异。真实生成与下载可能超过 5 秒，不能承诺永远不停留；已实现不清空画面、可跳过、回合结束不等待后台素材。闭环处理并非状态识别器，新模型结果仍可能需要人工复核。
